# ROS2 Publisher, Subscriber and Turtlesim

The required ROS2 task was completed.

The Publisher and Subscriber were modified to send and receive a message different from “Hello World”. The message used is “Hello from ROS2”.

The TurtleSim code was modified to make the turtle move in a square pattern instead of a circular pattern.

The following files were added to this repository:

publisher.py
subscriber.py
turtle_square.py

The work was completed using GitHub Codespaces on an iPad.
